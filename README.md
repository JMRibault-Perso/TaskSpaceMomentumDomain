# TaskSpace Momentum LLC — Website

## 📁 What You Have

This folder contains a complete, professional website framework for TaskSpace Momentum LLC:

- **index.html** - The main webpage with all content (placeholders marked `[PLACEHOLDER]`)
- **styles.css** - Professional styling and responsive design (indigo/momentum-orange palette)
- **CNAME** - Custom domain configuration for GitHub Pages (`taskspacemomentum.ai`)
- **PUBLISHING_GUIDE.md** - Step-by-step instructions to publish and connect the domain via Porkbun

## ✨ Features

✅ Modern, professional design
✅ Fully responsive (works on all devices)
✅ Smooth animations and interactions
✅ Contact form
✅ SEO-optimized
✅ Fast loading
✅ Easy to customize

## 🚀 Quick Start

### 1. Preview Locally
Open `index.html` in your web browser to see how it looks.

### 2. Fill In Placeholder Content
Every section marked `[PLACEHOLDER]` needs real content:
- Business description (hero + about section)
- Services / capabilities descriptions
- Standards & frameworks used
- Focus areas / industries served
- Featured initiative / case study
- Contact information (email, phone, address, LinkedIn)

### 3. Publish Online
Follow the detailed instructions in `PUBLISHING_GUIDE.md`.

**Method used:** GitHub Pages + Porkbun DNS (free and easy — same approach as [jmrresources.com](https://github.com/JMRibault-Perso/JMRResourcesDomain)).

## 🎨 Customization Tips

### Change Colors
Edit `styles.css` at the top (`:root` section):
```css
--indigo: #4338ca;      /* Primary brand color */
--momentum: #f97316;    /* Accent / CTA color */
--cyan: #22d3ee;        /* Secondary accent */
```

### Add Your Logo
Replace the "TSM" text mark in navigation with an image:
```html
<img src="logo.png" alt="TaskSpace Momentum" class="logo">
```
